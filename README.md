## 📖 Overview

This repository contains a comprehensive collection of HTML, CSS, and JavaScript examples and tutorials designed for learning web development fundamentals. The materials cover everything from basic HTML structure to advanced JavaScript concepts.

## ✨ Features

### 📝 HTML Fundamentals
- **Structural Tags**: `<html>`, `<head>`, `<body>`, `<header>`, `<nav>`, `<main>`
- **Text Formatting**: Headings, paragraphs, lists, and text styles
- **Forms and Input**: Form elements, validation, and user input handling
- **Semantic HTML**: Proper use of semantic tags for accessibility

### 🎨 CSS Styling
- **Selectors**: Class, ID, and element selectors
- **Layout**: Flexbox, Grid, and positioning
- **Responsive Design**: Media queries and mobile-first approach
- **Animations**: Transitions and keyframe animations
- **Modern CSS**: Variables, pseudo-classes, and pseudo-elements

### ⚡ JavaScript Concepts
- **Basic Syntax**: Variables, data types, and operators
- **Functions**: Function declarations, expressions, and arrow functions
- **DOM Manipulation**: Selecting and modifying HTML elements
- **Event Handling**: Click, input, and other event listeners
- **Async Operations**: Promises, async/await, and fetch API

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A text editor or IDE (VS Code recommended)

### Usage

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ernakkc/HTML-CSS-JS.git
   cd HTML-CSS-JS
   ```

2. **Open HTML files**:
   - Simply double-click any `.html` file to open it in your default browser
   - Or use a local development server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (with http-server)
     npx http-server
     ```

3. **Start Learning**:
   - Begin with `1. generalThings.html` for HTML basics
   - Progress through projects as you gain confidence
   - Experiment with code modifications to understand concepts
